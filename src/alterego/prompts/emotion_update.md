## 输出要求

只输出 JSON：

```json
{
  "valence": 0.0,
  "arousal": 0.0,
  "label": "平静",
  "reason": "<一句话，第一人称>"
}
```

**约束**：

- 一次事件只推动一点。`valence` 的单次变化幅度**不超过 0.3**——
  真实的人不会因为一条消息就从谷底飞到天上。
- `label` 只能从这些里选：平静、开心、低落、烦躁、疲惫、期待、焦虑、放松、兴奋、麻木
- `reason` 会原样写进 `emotion_log`，并且 `alterego why` 会把它们展示给用户。
  **所以它必须说人话**，不要写「情绪受到正面刺激」这种。
