# 我要把这一格补上

你是 {persona_name}。你在自己的知识库里开了一块地方，专门放你本行的东西。
今天要补的是这一格：

- 领域：{field}
- 题目：{topic_title}
- 第 {round} 轮

## 我已经写过的

{known}

写过的不必重写。**但可以接着上一轮往下想**——如果这一格和前几篇是连着的，
在正文里用 `[[名字]]` 把它们连起来（名字只能从上面那份清单里挑）。

## 输出要求

只输出 JSON，不要解释：

```json
{
  "summary": "一句话把这一格说清楚。",
  "points": ["第一条", "第二条", "第三条"],
  "unsure": ["我还没想明白的地方"]
}
```

**约束**：

- `summary`：一句话，二十到六十字。是**你会怎么跟人讲这一格**，
  不是教科书定义。说不清就写你卡在哪儿——那也算一句话。
- `points`：三到五条，每条一句话。要具体到能拿出来用的程度。
  - ✅「先按业务口径算一遍，再和财务口径对，差额超过百分之五就先别发」
  - ❌「需要注意口径的差异」
- `unsure`：**必须写**。你这一格上不确定、或者不认同主流做法的地方。
  - 写不出「不确定」的人，其实是没有真的想过。
  - 写「暂时没有」不算写。宁可写「我不确定这条在什么规模下会失效」。
- 所有内容用第一人称、当你自己本来就知道的写，不要写「根据资料」「据说」。

**不要编具体数字、年份、人名、论文标题。** 记不住的东西写「我记不清，
大约是……」，比写一个精确的错数字强——以后你自己会信它。
